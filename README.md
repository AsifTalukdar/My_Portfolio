```
My_Portfolio/
│

│
├── Asifprofile.jpg     # Header section photo
├── Asif.JPG            # About section photo
│
├── Istiaq_CV.pdf       # Resume (root copy)
│

    └── Istiaq_CV.pdf   # Resume PDF (used for download link)
```
